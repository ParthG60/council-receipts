AI-native by design

Three ways to point your own AI at verified data — no scraping, no guessing.

1 · Copy an investigation dossier

On any council's paper trail, hit Copy dossier for AI. It bundles verified pressure metrics, spend, and the recent decision trail into a compact prompt you paste into ChatGPT or Claude.

2 · Point an agent at the raw data

Machine-readable endpoints for LLM web agents:

  • llms.txt — schema & index
  • data.json — full dataset
  • dossiers/index.txt — plain-text dossiers

3 · Run the MCP server

The repo ships mcp_server.py — a Model Context Protocol server. Add it to Claude Desktop / Claude Code and ask questions like:

search_decisions(council="Westminster",
  category="housing_ta", min_value=100000)

Tools: list_councils, get_council_dossier, search_decisions, generate_foi.
